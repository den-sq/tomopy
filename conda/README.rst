TomoPy 1.15.3-densq.1 CUDA package
================================

This channel supplies the patched native algorithms for TomoPy 1.15.3, including
the gridrec correction-table bounds and spatial-gain fixes. It supports Linux
x86-64 with CUDA 12.9. Gridrec runs on the CPU using FFTW; GPU MLEM/SIRT support
is retained.

Install
-------

Activate the environment used by lftomo, then run:

.. code-block:: bash

   CONDA_AGGRESSIVE_UPDATE_PACKAGES='' conda install \
     --freeze-installed --override-channels \
     -c https://raw.githubusercontent.com/den-sq/tomopy/1.15.3-densq.1/conda/channel \
     -c conda-forge \
     'libtomo=1.15.3=cuda12.9h1234567_densq1_103' \
     'tomopy=1.15.3=pyhd8ed1ab_2'

The native package replaces stock ``libtomo``. The Python wrapper remains the
compatible conda-forge ``tomopy`` package, preserving imports and lftomo's API.
Conda downloads and installs the binary and resolves its runtime dependencies;
a compiler and a local checkout are unnecessary. The scoped environment setting
disables unrelated automatic package updates for this command.

Retain ``libtomo=1.15.3=cuda12.9h1234567_densq1_103`` in your environment
declaration or its ``conda-meta/pinned`` file so later solves retain this build.
Keep the HTTPS channel above in the environment's channel list when recreating it.

The complete dependency stack requires glibc >=2.28 and an NVIDIA driver
compatible with CUDA 12.9. OpenCV-based CPU MLEM/SIRT acceleration is disabled,
following the conda-forge CUDA recipe. Ordinary CPU gridrec and GPU MLEM/SIRT
are available.

Source and recipe
-----------------

The binary was built from source commit
``cf34df4b4f5206b86368be46cb63b4b62a595e68``. The recipe is based on
``conda-forge/tomopy-feedstock`` commit
``96d1b32390d5d5f46b32c21580dc07be9028acfd``. It retains the feedstock's native
build script, CUDA NPP shared-library patch, dependencies, and CUDA12.9/FFTW
variant. Fork changes select the corrected source, add the ``densq1`` build
marker, increment the recipe build number, and skip the unchanged Python output.

``sources/`` preserves the exact source archive used for this binary. Its
``.git_archival.txt`` contains version information derived from Git refs;
preserving the archive avoids checksum changes when those refs move. The
published recipe downloads these identical bytes from this branch. The recipe
embedded in the binary retains the original GitHub archive URL as build history.
``SHA256SUMS`` covers the binary and preserved source archive.

To rebuild, install conda-build and conda-index, then run from this directory:

.. code-block:: bash

   CF_CUDA_ENABLED=True CPU_COUNT=4 conda-build recipe \
     -m linux-64-cuda12.9-fftw.yaml --override-channels -c conda-forge \
     --no-anaconda-upload --output-folder channel

The recipe defines dependency and build settings. The channel metadata is
generated by conda-build/conda-index from package metadata; regenerate it after
publishing another build rather than editing dependency records manually.
